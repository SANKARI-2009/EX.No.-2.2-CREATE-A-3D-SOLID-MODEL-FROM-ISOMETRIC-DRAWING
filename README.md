# EX.No.-2.2 CREATE A 3D SOLID MODEL FROM ISOMETRIC DRAWING
## Date :

## AIM: 

To create a 3Dmodel from the given isometric drawing using fusion 360 tool. 

## REQUIREMENTS:
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

#Procedure

STEP 1: Start the Sketch Command 
    Open Autodesk Fusion 360 and select the Design workspace. Click on Create 
Sketch from the Solid toolbar to start a new sketch. The three reference planes (XY, XZ 
and YZ) will appear on the screen. 

STEP 2: Select the Sketch Plane 
       Select the Top (XY) Plane from the available reference planes. The sketching 
workspace will open with the origin and coordinate axes visible on the screen. Make 
sure that the correct plane is selected before starting the sketch. 

STEP 3: Create a Sketch 
         Sketch → Rectangle → Center Rectangle and move the cursor to the 
origin point. Click once to define the centre of the rectangle. Press the Tab key and 
enter the width as 56 mm and height as 18 mm. Press Enter to confirm the dimensions. 
Next, select Sketch → Arc → Center Point Arc and create the required arc by 
selecting its centre point and two endpoints. Enter the radius as 18 mm using the 
dimension command. Then select Sketch → Circle → Center Diameter Circle and 
create the required circles on both sides of the sketch. Enter the diameter as 16 mm. 
Check the position and dimensions of all the sketch features and click Finish Sketch.

STEP 4: Extrude the Sketch in XY Plane 
       Select Solid → Create → Extrude and choose the required closed sketch profiles. 
Enter the extrusion distance as 8 mm in the dialogue box. Check the direction and 
preview of the extrusion. Select the appropriate operation, such as New Body or Join, 
according to the required model. Click OK to complete the extrusion and create the first 
3D solid feature. 

STEP 5: Start a New Sketch 
       The existing 3D model will appear on the screen. Select the top surface of the 
model to continue the desiClick on Create Sketch from the Solid toolbar to begin

STEP 6: Select the Top Surface 
       Click on the top surface of the 3D block to select it as the sketch plane. Wait until 
the sketching workspace opens on the selected face. Check the origin and reference 
edges before drawing the next feature. 

STEP 7: Create a Rectangle 
     Select Sketch → Rectangle → Center Rectangle and move the cursor to the 
required centre point. Click once to begin drawing the rectangle. Enter the width as 40 
mm and height as 10 mm using the Tab key. Press Enter to confirm the dimensions and 
complete the rectangle. Check the position of the rectangle and click Finish Sketch.

STEP 8: Extrude the Rectangle 
       Select Solid → Create → Extrude and choose the rectangular sketch profile. 
Enter the extrusion distance as 32 mm in the dialogue box. Check the extrusion 
direction and select the appropriate operation to connect the feature with the existing 
model. Click OK to complete the extrusion. 

STEP 9: Create a Triangle 
        Select Create Sketch and choose the required face or plane for drawing the 
triangle. Navigate to Sketch → Polygon → Inscribed Polygon or use the appropriate 
triangle sketch tool available in Fusion 360. Position the triangle at the required location 
and enter the specified width as 32 mm and height as 12 mm, according to the drawing. 
Check the shape and dimensions of the triangle and click Finish Sketch. 

STEP 10: Extrude the Triangle 
       Select Solid → Create → Extrude and choose the triangular sketch profile. Enter 
the extrusion distance as 6 mm on both sides by selecting the Symmetric direction 
option, if the drawing requires equal extrusion on either side of the sketch plane. Check 
the preview and click OK to complete the extrusion. 

STEP 11: Create a Polygon 
        Select Create Sketch on the required face of the model. Navigate to Sketch → 
Polygon → Circumscribed Polygon. Move the cursor to the required centre point and 
click to start creating the polygon. Set the required polygon size according to the given 
drawing and enter the dimensions as 40 mm and 30 mm, wherever applicable. Set the 
required number of sides to match the drawing. Check the shape and position of the 
polygon and click Finish Sketch. 

STEP 12: Extrude the Polygon 
     Select Solid → Create → Extrude and choose the polygon sketch profile. Enter the 
extrusion distance as 10 mm in the dialogue box. Check the direction and operation of 
the extrusion. Click OK to complete the feature and add it to the existing 3D model. 

STEP 13: Create Circles 
     Select Create Sketch on the required end face of the polygon feature. Choose 
Sketch → Circle → Center Diameter Circle from the toolbar. Move the cursor to the 
required centre point on the end face and click once. Draw two concentric circles by 
using the same centre point. Enter the inner diameter as 20 mm and the outer diameter 
as 30 mm, according to the given drawing. Check the position and dimensions of both 
circles and click Finish Sketch. 

STEP 14: Extrude the Circles 
       Select Solid → Create → Extrude and choose the required circular ring profile 
between the two concentric circles. Enter the extrusion distance as 10 mm on both 
sides by selecting the Symmetric direction option, if required by the drawing. Check the 
extrusion preview and select the appropriate operation. Click OK to complete the 
circular feature. 

STEP 15: Complete and Save the 3D Model 
      After completing all the modelling operations, rotate the model using the ViewCube to 
observe it from different directions. Check the front, top, side and isometric views to 
verify the shape and dimensions of the model. Make any necessary corrections to 
match the given isometric drawing.
